How Editing Works
Use presets and guided fields first. This beta demo is a World Explorer overlay preview, not an OpenStreetMap contribution tool.
Overlay Editor Beta Demo
This workflow previews World Explorer overlay editing on top of the imported world. It is not connected to OpenStreetMap contribution and it does not edit base ingest data.
1. Select a base feature to patch, or choose a preset and draw a point, line, or polygon directly in the 3D world.
2. Edit vertices, tags, and 3D properties like height, levels, roof shape, bridges, tunnels, and entrances.
3. Validate the overlay, preview it locally, and save draft revisions without affecting the public world.
4. Submit the overlay for moderation. Admin review decides whether it needs changes, is rejected, or is approved and published.
5. Published overlays merge into runtime render and traversal layers without mutating the imported base dataset.

⚙️ Driving Mode ▼
🚗 Driving Mode:
• Arrow Up/Down - Drive forward / reverse
• Arrow Left/Right - Steer left / right
• WASD - Look around; chase view recenters automatically
• Space - Handbrake
• Ctrl - Boost
• C - Camera view
• F - Cycle drive / walk / drone
• M - Toggle map
• N - Next city
• B - Open / close Build with Blocks
🚤 Boat Mode:
• Arrow Up/Down - Throttle / Reverse
• Arrow Left/Right - Steer
• WASD - Look around
• Space - Brake / Hold position
• G - Enter / exit boat travel
• C - Camera view
• Fishing button - Open fishing while the boat is stopped
• E - Cast / set hook; hold Space to reel; hold Q to give line
• J/K/L - Rod left / center / right during a fight
• Use the bottom Wave Intensity slider for calm, moderate, or rough water
🚶 Walking Mode:
• Arrow Up/Down - Move forward / back
• Arrow Left/Right - Turn left / right
• WASD - Look around
• E - Enter/exit building interior
• Space - Jump
• Space at a wall - Climb / wall jump
• Shift - Run (2x speed)
• Right Click + Drag - Mouse look
• C - Camera view
• F - Cycle walk / drone / drive
• B - Open / close Build with Blocks
🚁 Drone Mode:
• Arrow Up/Down - Fly forward / back
• Arrow Left/Right - Turn left / right
• WASD - Look around
• Mouse - Look around
• Space - Fly up
• Shift/Ctrl - Fly down
• F - Cycle drone / plane / drive / walk
• B - Open / close Build with Blocks
✈️ Plane Mode:
• Arrow Up/Down - Nose down / pull up (inverted)
• Arrow Left/Right - Bank or ground steer
• X/Z - Increase / reduce throttle
• Space - Wheel brake on the ground
• WASD - Look around
• C - Chase / cockpit / overhead camera
• P - Enter / exit plane mode
🚀 Rocket Mode:
• Arrow Keys - Steer rocket (yaw/pitch)
• Space - Thrust / Boost
• Shift - Brake / Decelerate
• X - Mining pulse in generated asteroid regions
• LAND ON ... Button - Land when in range
🌊 Submarine Mode:
• W/S - Forward / Reverse thrust
• A/D - Turn left / right
• Space - Ascend
• Shift/Ctrl - Descend
• Arrow keys - Alternate steering controls
• Explore the reef shelf and open deep ocean
