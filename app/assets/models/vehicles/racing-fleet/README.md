# Additional performance vehicles

The BMW M3 E46 by MMC Works is a model of the real road-going sports coupe.
It is not a GT3 or GTR competition model. Its original body and interior use
CC BY 4.0; the adjacent licence and manifest preserve author, source, hashes,
measurements and modifications.

The reproducible offline derivative script takes the pinned glTF source,
normalizes it uniformly to metres, straightens the 20 degree showcase wheel
pose, separates four steering/spin pivots and fixed calipers, bounds geometry
and texture sizes and prepares the glazing for the game renderer.

Vehicles use the existing shared model cache, garage ownership, wallet,
condition, upgrades, camera mounts, transport and racing controllers. They
remain outside ordinary traffic populations. Handling and prices are game
tuning; no manufacturer simulation or endorsement is claimed.
