  Chrome. Use the existing owned-browser cleanup helper. Check disk first.

  retain failed/interrupted receipts and screenshots.

  evidence receipt. Reuse a successful receipt only when those inputs and its

  assertions instead of launching a city per feature. Separate fetch, compile,
