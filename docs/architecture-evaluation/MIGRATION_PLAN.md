# Staged migration plan

Each stage keeps the browser runnable. No production deployment is authorized by this investigation. Retain the release candidate while experiments remain isolated.

| Stage | Deliverable | Exit evidence | Rollback boundary |
| --- | --- | --- | --- |
| 0 Baseline/ownership | Pin source/artifact, source inventory, performance ledger | Build identities and exact evidence scope recorded | No runtime change |
| 1 Bounded lifecycle correction | Invalidate stale lazy-service loads and add targeted tests | Reproduction fails before/passes after; integration smoke still required | Revert registry patch and its tests together |
| 2 Normal-player profiles | Complete A–T with stable hardware and one workload at a time | Actual movement, usable frames, settled teardown, CPU/heap/GPU/copies separately | Remove profiler only; no production policy changes |
| 3 First portable building boundary | Resolved building record before Three mesh creation; reuse provenance/identity | Same source location; height/footprint/entrance/property/capture parity and no duplicate retained graph | Keep old pass behind temporary single-authority adapter until equivalent; revert one consumer slice |
| 4 Narrow types/contracts | Check command/result/frame/building/worker interfaces | Contract and saved-data compatibility fixtures; no browser payload regression | Revert type/build additions without changing persisted schema |
| 5 Measured algorithm/lifetime fixes | Highest observed stalls or retained owner, one at a time | Controlled before/after data, same hardware/source/assets/quality, no lost behavior | One bounded commit per change |
| 6 Worker extensions if warranted | Move measured compiler job through existing scheduler/transfer protocol | Main-thread and total load cost, bytes copied, cancellation/fallback and error paths | Existing JS path remains available; single chosen authority |
| 7 Renderer upgrade experiment | Pin modern Three, adapt selected shader/loader/postprocessing slice | Earth/space/interior/planet visual gallery, controls, memory/context teardown on target browsers | Separate branch/renderer switch, no asset/save migration |
| 8 Optional Wasm or WebGPU compute | One measured bulk kernel, if prior evidence warrants it | End-to-end boundary timing wins, memory/mobile/startup acceptable, outputs equivalent | Existing JS/worker path; no persisted format dependency |
| 9 Portable location proof | Actual provider input → versioned records → current browser renderer | Terrain, roads, buildings, entrances, POIs, units/provenance preserved; round-trip and visual checks | Isolated prototype or adapter removed without losing source authority |
| 10 Future client decision | Godot vs Unity investigation using the same proven records | Equivalent difficult vertical slice and maintenance/cost estimate | Browser remains primary; native implementation separately authorized |

Stage 3 is not permission to redo the entire world compiler. It starts with one source-backed building at a representative real location. Broaden only when the record serves collision/entry/rendering without double storage or changed identity. The optional portability proof may be moved earlier if it can reuse existing records without inventing a duplicate model.

## Controlled acceptance procedure

Pin location and source hashes, browser/driver, viewport/DPR and quality; separate cold and warm caches. Record observer overhead separately. Use real elapsed time and real movement; do not compare a stationary scripted scene to sustained travel. Retention checks require repeated equal cycles and settle times. No threshold increases or skipped cases disguised as success.

Stop on a new failure, diagnose it, then rerun only affected scopes. Retain unchanged passing evidence tied to its source/artifact identity. Software CI covers functional journeys while hardware sessions establish responsiveness; neither substitutes for the other.

## Data migration discipline

Version contracts before changing persisted shapes. Keep old-save read compatibility, idempotency/receipt IDs and authorization semantics. Avoid dual writes. Backfill only verified source relationships; uncertain aliases stay unresolved. Asset paths/licenses/content hashes must survive any new packaging. Native adapters cannot privately reassign building identity, currency or cargo custody.

## Current execution state

Source inventory, primary-source research, design, deterministic registry repair and its browser-component check completed. The full source investigation, browser integration smoke, A–T performance measurements and portable-location proof remain open. This plan does not mark the product production-ready or authorize a native rewrite.
