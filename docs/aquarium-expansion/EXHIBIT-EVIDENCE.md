## Required exhibit record

Stable venue/wing/floor/exhibit IDs; evidence URL and review date; confidence of
placement; authored habitat-volume ID; species scientific identity; independently
licensed model ID; model scale/orientation/animation; educational text; interaction
anchor and line of sight; load and failure states; Journal event ID; attribution.
One tank ID can have viewing anchors on several floors. It owns one bounded
population and one simulation clock. Exhibit placement must not duplicate animals.

## Initial reef learning sequence

1. **Recognize the shark:** observe the dark fin tips and compare the outline
   with the reviewed model. A completion action saves a study note; it does not
   report a wild sighting or a verified aquarium census.
2. **Read the reef:** inspect branching structure and fish shelter. The existing
   Smithsonian scans can represent fabricated reef structure after appropriate
   recoloring; they are not live scans of this institution's habitat.
3. **Follow the turtle:** compare flipper-driven motion with the shark's tail.
   Use a correct, independently licensed green sea turtle, not a loggerhead or
   an individual-rescue replica inferred from photographs.

Free walking remains available throughout. Reading never rotates the whole living
habitat or stops a real-world institution's activity. Existing game pause governs
simulation while the panel has focus; close returns control to the same player.
Study-note deduplication survives exit, reload and content revisions. Existing
Field Guide uses species metadata only when its authority supports this educational
provenance; otherwise Journal is sufficient and no wild-observation credit is issued.
