## Ten deep reviews

### [SamG-Coder/ThreeMuseum](https://github.com/SamG-Coder/ThreeMuseum/tree/f247052675d80ff0188709cab5facb4035bfaa49)

Inspected README, package.json, MIT LICENSE and public/models/CREDITS.md. Three 0.180.0 and its game UI cannot replace r128 owners. Repository claims 30 GLBs, roughly 95 MB and 3.42 million triangles across 11 spaces; these are upstream inventory figures, not local measured costs. The F01 Triceratops credit points to Smithsonian CC0. Other authored educational models do not imply scientific reconstruction fidelity. Selected the original Smithsonian asset, not this app’s implementation.

### [nandana-das/interactive-3d-virtual-museum](https://github.com/nandana-das/interactive-3d-virtual-museum/tree/00011408cf92b33189b1fe84dab5502abbafd134)

The originally supplied virtual_museum_project URL redirects to this repository. README describes six halls, tours and procedural exhibits. No license was returned or found in the inspected root/tree. Do not copy code/assets without permission; a similar feature can be implemented through our existing authorities.

### [lbartworks/openvgal](https://github.com/lbartworks/openvgal/tree/5df0256efe3fa559a8334473b7628a9b90619c17)

Inspected README, MIT license and model tree. Small venue GLBs range approximately 24 KB–1.7 MB in repository tree metadata, but their wall openings, coordinates, separate textures and fit remain unverified. Useful future authored-shell experiment; current gallery uses compiler-generated walls because visual geometry and collision must agree.

### [barisulgen/personal-museum](https://github.com/barisulgen/personal-museum/tree/add634d01fb131fe91666ac839a6c676b4694c28)

Inspected README, package.json and LICENSE. package license says ISC while LICENSE text is MIT. Three ^0.183.0, idb 8.0.3 and Vite form a standalone private photo-gallery application. Copying that stack adds a second persistence and control model. Default art/audio require separate rights; reject implicit inheritance of the code license.

### [Leo-shuanglin/3d-museum](https://github.com/Leo-shuanglin/3d-museum/tree/bc7e58f8162c4d8599e790be7213a99044f56638)

Inspected README, MIT LICENSE, dependency metadata and attribution inventory. Its 53-object collection has heterogeneous licenses, including NC/NC-SA. The OpenVGAL venue’s permissive license does not clear those exhibits. Whole-bundle import is rejected; direct Smithsonian/Met sources avoid mixed rights.

### [Smithsonian/dpo-voyager](https://github.com/Smithsonian/dpo-voyager/tree/0ed663383e45693fb31c02cc3cc6067768d44c6a)

Inspected README, Apache-2.0 license and package metadata (0.67.0, Three ^0.184.0, Lit/editor dependencies). It supplies a sophisticated scene/tour publishing platform, not a geographic building authority. Use its provenance and progressive-content concepts as references. Do not bring its viewer/editor into game startup or inherit model rights from software license.

### [donmccurdy/glTF-Transform](https://github.com/donmccurdy/glTF-Transform/tree/3797aad585021e68cf5fbf3f2fba37783596ffac)

Inspected README, MIT LICENSE, package and file inventory. Used installed 4.5.0 NodeIO/functions/extensions for offline transform only: bounded embedded resources, display normalization, Meshopt simplification and texture resizing. Actual output counts/hashes are measured by our importer. Tool licensing does not change input rights. No downloaded build scripts executed.

### [KhronosGroup/glTF-Validator](https://github.com/KhronosGroup/glTF-Validator/tree/602c54043ba66856b2e68c40fdf2bced975cdb8a)

Inspected README, Apache-2.0 LICENSE and package/file inventory. Its role is structural conformance, not malicious-content approval, geographic fit or copyright clearance. Current importer rejects external URIs/unknown extensions and checks pinned source/output; adopting the full validator remains a separately labeled improvement, not a claimed completed validation.

### [gkjohnson/three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh/tree/b0935a7ec5904d2c009880be8da843b2637f185d)

Inspected README, MIT LICENSE and package.json. Current 0.9.15 peer requirement is Three >=0.159.0, beyond this app’s r128. Imported museum scan collision would also undermine existing wall/floor authority. Defer package adoption; compiler walls and explicit exhibit envelopes need no BVH.

### [isaac-mason/recast-navigation-js](https://github.com/isaac-mason/recast-navigation-js/tree/8769e8b9995f127033af9f6e6eeac3fad7d66201)

Corrected the originally guessed nonexistent owner spelling. Inspected README, MIT LICENSE, root package and workspace tree. It wraps Recast/Detour in WASM, supports offline generation and optional Three/PlayCanvas bindings, and has an upstream-license boundary. Native two-room navigation already works via validated doors; defer runtime WASM/crowd ownership. If future tours/NPCs need navigation, test an offline exported navmesh without replacing Walk.

## Costs and acquisition

No subscriptions or paid content are selected. The three near assets total 6,137,412 bytes; the two optional lower-detail files total 1,756,284 bytes. A cold visit therefore transfers about 6.14 MB of exhibit payload, not the full collection at startup. Ten thousand uncached visits imply about 61.4 GB of payload egress before protocol overhead, shell assets or cache hits. This is a traffic estimate, not a free-tier or billing guarantee. Hosted costs depend on the existing provider plan. Offline conversion runs on the existing machine; never execute source-repository scripts.

Internet Archive and NASA catalog leads were examined but did not establish selected-file rights/version evidence; they are not counted to inflate the 50-candidate catalog.
