# Museum expansion gates

These are finite publication gates, not promises that every mapped museum has a
playable or accurate interior. Current delivery is the reviewed Peale-associated
interpretive front-floor gallery.

| Gate | Exit requirement | Current evidence |
|---|---|---|
| Existing ownership audit | Entry, capture access, movement, layout, assets and saves have explicit existing owners | Implemented; EXISTING-SYSTEM-AUDIT and ARCHITECTURE |
| Source research | 50 credible candidates, 10 deep reviews, source/license decisions | Complete research inventory; OPEN-SOURCE-CANDIDATES |
| Safe content intake | Bounded pinned inputs, local output hashes, no external model resources | Implemented for Smithsonian GLB and Met image paths; component checks |
| Playable first site | Canonical building match, connected galleries, three real licensed exhibits, labels, rotation, Journal, return | Local actual-game journey; VERIFICATION |
| Finished architecture | Supported room relationships, finished surfaces, furniture, bounded lighting, clear navigation | Local front-floor interpretation; ARCHITECTURAL-REFERENCES |
| Failure and lifecycle acceptance | Missing/slow assets, late completion, reentry, resource release, mobile reading | Mixed component/browser evidence; final scope in VERIFICATION |
| Release acceptance | New immutable artifact, complete source and release matrix, budgets, save rollback, real device disclosure | Open; broader release gates remain failing/unrun |
| Next actual institution | Verified public entry and measured or clearly bounded layout; rights for each imported item; same acceptance journey | Research-only mapped candidates; no automatic campus-wide publication |

The candidate inventory includes Baltimore and New York institutions. Publication
must stop for a candidate with only a POI point, an unresolved multi-building
campus, incompatible building parts, uncertain object rights, or unsupported
indoor levels. Names and proximity are not admission evidence.

Accurate full Peale expansion needs current measured rooms/doors/stairs and an
independently checked accessible route. The public guide supports topology but
not dimensions; historical descriptions cannot certify current exhibitions.
No empty upper-floor shells, locked fake doors or borrowed institutional claims
are a substitute for that evidence. Additional galleries should extend the same
layout/import/save owners rather than create another museum-specific game.
