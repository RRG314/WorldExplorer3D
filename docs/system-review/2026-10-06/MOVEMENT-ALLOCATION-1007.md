## Implemented reductions

Shoreline nearest-point queries now compare scalar segment distances and allocate only the selected point/tangent. They retain exact source-order ties, degenerate segments, independent result records and same-array geometry edits. Opaque sorting returns an integer depth sign while preserving authored layers and all existing tie breakers.

In the same loaded world, four 60-second input windows alternate original/candidate/original/candidate code through test-only module instrumentation. Shoreline self allocations fall from 131.55 / 125.92 MiB to 17.00 / 16.75 MiB; original comparator allocations are 92.50 / 109.00 MiB and neither candidate has a sampled comparator allocation. Full allocation totals and hitches vary, including a higher total in the final candidate window. This proves the targeted reductions, not a whole-game stall fix or global memory improvement. `output/architecture-evaluation/movement-allocation-causal-1007/allocation-comparison.json`. Final screenshot inspected; original source restored in both control windows.

Pending transport selection now queries at most nine cells of the existing region grid. It preserves the previous queue-order tie breaker, including reinsertion after eviction. A 10,201-region oracle case, signed/exact boundaries, distant/invalid coordinates, real worker compilation, return retirement and superseded publication pass all 17 component checks. No coverage, residency, source or physics budget changed.

## Completed movement and residency checks

The final unprofiled source drive reproduces a 1,148.7 ms pause despite the reductions. Walking travels 213.7 units over 90 seconds, with a 281.3 ms worst frame. Driving travels 394.8 units over 90 seconds. No custody interruption or browser errors. The passing per-function results do not close the active-play performance gate.

Five controlled region visits at offsets up to 7 km and return retain all 49,023 buildings and 18,952 roads. Transport keeps 9–12 of its 16 allowed active regions, records 36 retirements, reaches idle readiness and returns to identical contact heights. This checks bounded detail residency, not controls-only worldwide travel. Evidence: `output/architecture-evaluation/movement-allocation-final-1007/report.json`.
