# Visual directions — revised after owner feedback

The owner rejected the first preview because it changed structure while retaining one visual style. The revised [Visual Design Studio](index.html) presents five different art directions. The earlier Atlas/Expedition/Workbench choices are navigation research, not accepted appearance choices. The previous Roam selection does not constrain this new visual comparison; production retains its existing appearance until a new direction is selected and implemented.

| Direction | Visual language | Composition and components |
| --- | --- | --- |
| TRAIL | Cinematic graphite and warm coral, condensed display type, cut corners | Large world/location typography, open scene, edge-mounted mission, compact map and strong vehicle readout; dramatic image-led home and activity cards. |
| ORBIT | Midnight blue, cyan, monospace instrumentation and precise square geometry | Grouped data panels, structured navigation, flight/mission framing, grid-backed planning pages, sharp kit slots and technical readouts. |
| FIELD | Warm paper, olive ink, serif headings and editorial photography | Print-like header and tabs, inset paper HUD, folded-map treatment, editorial home, photo-led Journal and clear research/report hierarchy. |
| CURRENT | Bright white, cobalt blue, modern sans type, generous rounded controls | Explicit labels, clear contrast, roomy cards, approachable navigation, large phone targets and a cleaner universal HUD. |
| NOVA | Deep violet, lavender, light typography, translucent layered glass | Floating task panels and dock, restrained radial instruments, rounded maps, immersive imagery and media-led planning surfaces. |

## How to compare

- **Compare styles:** five rendered interfaces appear immediately. Varied showcase uses a suitable scene for each direction; choose one shared scene to compare the same environment across all five.
- **Full preview:** explore the chosen style's in-world HUD, start/continue screen, map, careers, kit/garage, Journal, creation editor, rooms and settings. Switch to its phone composition.
- **Screen board:** see nine actual HTML interface compositions together, then open any one at full size.

The studio demonstrates real typography, surfaces, borders, icons, spacing, layouts and interactive screen changes. The imagery is concept scenery, not a screenshot of newly implemented game graphics. Sample progress, people, vehicles, map layouts and readings are fictional presentation data. The UI is HTML/CSS/JavaScript; no production account, save, room, reward, physics or publication API is connected.

All source inventories, domain ownership and progression/save requirements remain in the existing plan. A visual choice changes the proposed design system and its screen compositions; it does not authorize a second gameplay engine or a new save authority. Once selected, revise the implementation specification around that direction and use the existing finite stages. Real users/devices and accessibility evaluation remain required for implementation acceptance.
