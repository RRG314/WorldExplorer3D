The reception building is mapped OSMway1062199727. Training-room distribution is interpretive and must be labelled accordingly. Avoid inventing exact unknown rooms or placing machinery across an existing road.

The game supplies an interpretive supported route, solid machine barriers and an existing lift transfer between verified landings; no continuously moving cabin is claimed.

Mapped identity/footprint and existing access admission are required before installing content. Homes, captures, mapped indoor data and access-denied definitions retain their priority. The in-game training visit does not grant real-site access or a GPS visit. Current [CMS visit information](https://cms.cern/interact-with-cms/on-site-visits) has real-world restrictions; do not present the game as a booking/access service.
