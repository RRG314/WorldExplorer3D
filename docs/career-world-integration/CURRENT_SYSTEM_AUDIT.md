## Ranked findings

1. **High, reproduced:** explicit first-lesson instructions hidden by `gameplay-shell.css`. Local repair exposes only original consented guidance; ambient Observe remains quiet. Boundary verification is separate from the proposed redesign.
2. **High, source + N:** Today presents story, career-ish labels, nearby tools, routes and Sandbox paths before one clear first objective. Make a single current-task projection with secondary choices deliberately expandable.
3. **High, S:** account identity, local character and device Journal scopes are different. Do not promise cloud save, isolate users by visual focus, or silently merge sign-ins.
4. **High, S:** no persisted starting/active career focus lifecycle currently spans all systems. `activeExperience` and transient `discovery.careerFocus` cannot be relabeled as such. Add optional metadata only after architecture approval.
5. **Medium, N:** Learning/replay is in globe Settings rather than in-game Controls. Provide a deliberate access path through the existing tutorial controller; do not make instructions permanently flash.
6. **Medium, S:** Expedition pilot’s first assignment is a road delivery; engineering is a useful workspace path, not a complete industrial engineering profession. Names must match scope.
7. **Medium, measured source:** game geology endpoint still describes conterminous coverage. CNGM v2 announcement does not upgrade that endpoint. Add actual provider identity/version verification before expansion.
8. **Medium, N:** cold world entry took roughly a minute in two observations. No credible multi-sample median, causal profile or human learning-time conclusion yet. Loading/recovery remains part of onboarding, not cosmetic polish.
9. **Medium, source/historical audit:** broad mutable context and compatibility writers remain. Refactor demonstrated conflicts incrementally; a new general framework would increase migration risk.
