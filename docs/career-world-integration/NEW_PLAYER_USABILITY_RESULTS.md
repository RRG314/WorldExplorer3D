# New-player observations and limits

This is a fresh-profile **automation audit**, not a human usability study. No uninstructed participant, child, assistive-device user or retention cohort was tested. The operator knew the source and could choose selectors. Those facts limit what the result establishes.

## Results by evidence boundary

| Observation | Evidence | Interpretation |
| --- | --- | --- |
| Guest can enter ordinary world without account/attribute wizard | Desktop and phone clean staging captures | Basic entry exists; account creation and full character customization were not newly exercised. |
| Requested first-movement guidance invisible | Both computed CSS and opened screenshots | Reproduced high-priority presentation regression. Source controller existed and progressed. |
| Movement and native phone controls work in observed start | Desktop normal keys/look, phone touch; lesson Move→Interact | Does not certify all movement/vehicles/devices or explain ambiguous later detector approach. |
| First actual result can be recorded and reviewed | Native First Bearings Tulip tree virtual habitat finding, exact Journal event, badge | Real playable onboarding path exists. Result is game-authored habitat evidence, not a real species observation. |
| Unclear hierarchy | Today and Backpack images | Several chapter/route/tool/Sandbox layers compete. This is an expert inspection finding; novice confusion rate is unmeasured. |
| Tutorial completion bridge works for this result | Final v6 state complete, exact Journal result visible | Hidden intermediate card caption was stale. No event-bridge repair justified. |
| Phone first-objective entry | Twelve native-input actions, no driver error | Narrow pass; full phone task/result/return is not newly accepted. |
| Source repair works | Fresh ordinary source phone seven actions, actual card/details/dismiss/touch/menu | Independent repair only. It does not implement the broader career redesign or stage it. |

## Failures kept separate

Expired transient Resume selector; redundant close after entry already closed the panel; early post-reload menu actions before world readiness; earlier unbounded visible-control filter included offscreen elements. Corrected helper waits/filter are not evidence those product actions were broken. All failed images/logs remain. Final reload Journal was not observed after world readiness, so no fresh persistence pass is claimed there; prior unchanged persistence receipts remain accepted.
