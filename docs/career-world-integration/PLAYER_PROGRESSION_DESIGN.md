# Progression that makes the work matter

Use the existing action-based character and durable results. A player should understand what they did, what changed, where it is kept and what is worth trying next. Return reasons should come from meaningful unfinished work and opportunities, not obligatory streaks or duplicated score systems.

## Layers and purpose

| Existing layer | Purpose | Presentation |
| --- | --- | --- |
| Character background/attributes/traits | Starting assistance and identity | Optional creation detail; never replaced when switching interest. |
| Specialties/proficiencies | Practice across related work/tools | Show a small relevant award after real work; expanded skill sheet in Profile. Current rank thresholds remain unless separately balanced. |
| Explorer story points/badges | Breadth and memorable milestones | Explain why a result matters, avoid a second career-wide global level. |
| Domain course/mission/assignment records | What was actually completed, method, evidence, continuation | Continue/review original work; no UI-only completion. |
| Equipment/vehicles/property | Useful access and personal expression under original economy | A capability or project enables something tangible; do not require purchases for basic learning. |
| Qualifications | Specific advanced readiness | Require original evidence and a real award path before marketing as earnable. No arbitrary certification currency. |

## Existing safeguards

`character/progression.js` maps one event to related specialties/proficiencies and rejects already rewarded event IDs. Repetition diminishes under existing rules; changing car/loadout does not evade course repetition identity. Planetary geology can project Space plus Geology. Canonical claim/item transactions handle durable item dedup separately from bounded skill ledgers. Explorer milestones and character practice remain separate projections of the same work, not competing inventories.

## A first session and a reason to return

First action: move/look. First useful action: one valid interaction or field task. First outcome: an actual saved observation, course result or construction/room event. Review it in Journal. Then offer three paths: Continue this interest, Try another interest, or Roam freely. A career tutorial advances only when its original domain evidence is committed, not after pressing Next.

Early return: resume the unfinished course/route without re-granting tools; review an actual album/report; compare a second case; improve a clean lap; visit the personal workspace; meet a friend in an existing room. Mid-term: apply a familiar method in another supported context, improve tool practice, maintain a useful vehicle and make a shareable original artifact. Long-term: complete meaningful course variants, build a personal body of work and contribute to a deliberately scoped shared goal.

Do not award for opening every menu, switching focus repeatedly, walking in place or importing fabricated evidence. Do not represent source uncertainty as player failure. Observation can be meaningful without extraction, spending or a winning competitive result. Preserve accessibility alternatives and supported noncollecting study methods.

## Evaluation

Define completion, successful resume, voluntary second task and understandable result before measuring retention. With analytics consent, use bounded event IDs for task offered/accepted/result committed/result reviewed/next chosen; avoid raw coordinates/private photos/complete Journal uploads. Distinguish errors, unavailable geography and voluntary opt-out. D1/D7 returns are prospective metrics, not proven gains from these previews. Use mixed-age and mixed-experience user sessions before tuning pressure or rewards.
