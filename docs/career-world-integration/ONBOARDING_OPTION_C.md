# C — Explore first, help when requested

Flow: choose place → enter freely → optional Help/Activities → select valid task → real result/Journal when desired. No compulsory lesson, focus or background choice.

Best for experienced players and returning Explorers. It preserves the primary world fantasy and minimizes interruption. Weakness: a new player may not know what is possible or how to keep progress. A quiet but visible Help/Continue entry and one understandable Activities handoff are essential; hidden useful instructions are not “minimalism.”

Help opens the original tutorial or current-task explanation deliberately. A first actual result may invite one unobtrusive Journal review, respecting consent/notice duration and no recurring flash. No automatic career selection from early movement, no tool grants merely for opening help and no penalty for ignoring progression.

The same entry/geography/equipment/room rules apply. An active trip owns recovery guidance. Learning can be replayed later without changing item/course history. Save scope is still explained, including the shared device Journal; “guest” does not mean disposable unless storage is unavailable.

Preview: [explore-first](index.html?intro=C&model=B&composition=atlas&device=desktop). Immediate free-explore route remains available in A/B as well. The preview is a simulation; source free-exploration and travel acceptance is reused.

Approval outcome: keep this as a first-class route even if B is default. Release stop: no mandatory modal/creation/task, Help and Continue are findable, all existing worlds/modes available under original conditions, valid progress can happen without completing a tutorial.
