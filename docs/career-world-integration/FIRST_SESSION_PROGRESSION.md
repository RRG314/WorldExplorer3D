# A complete first session

The stopping point is a meaningful result, a visible durable record and a voluntary next choice. It is not opening a career menu, completing four text slides or visiting every navigation area.

| Stage | Player learns / does | Existing authority and durable evidence | Afterward |
| --- | --- | --- | --- |
| Foundation | Move/look and understand contextual action | Original controller + First Journey; lesson progress only, no item reward | Try a real interaction/task or skip guidance |
| First work | Accept and complete a compatible activity | Original adapter/domain, geography/equipment/current-world rules | Record/review actual result |
| First memory | Understand what was kept and where | Canonical Journal event/report, actual save scope, existing skill projection | Continue related work / another interest / free explore |
| First direction | Optional focus, prepare for useful next task | Proposed preference only; original Backpack, course-provided tools and store authority | No reset, forced purchase or duplicate grant |
| First return | Resume unfinished task, compare another case, improve route/lap or visit workspace | Original domain continuation and records | Progress through actual work, not repeated onboarding |

The current ordinary desktop path already reaches a real virtual habitat record and First Bearings badge. This confirms a viable foundation but not ideal usability. A subsequent researcher, racing or creative path can become the next direction without forcing every player through the entire opening story. Existing workspace access from research/Racer completion stays supported.

## Rewards and pacing

Keep existing point/practice rules initially. Explain relevant awards once after the committed result; no simultaneous XP/coins/career meter popup stack. Tools and basic instruction are available without purchase. Preserve noncollecting methods. Each later unlock must say what it enables: a real supported method, qualification, equipment use or useful project, not an empty title.

An early session should reveal only movement, one action, saving/review and the next choice. Detailed attribute math, multiplayer governance, material economy, complex star navigation and all twenty careers are optional depth. This is information sequencing, not deleting those systems.

## Interruption and failure

Close menu/pause/hidden accepts no fake effort. Quota or failed save cannot award completion. Leaving a task preserves original durable partial state. Rejoin a shared room through its existing admission. A failed world load offers retry or globe without corrupting last valid state. Returning with a completed lesson never triggers creation or starter grants automatically.

## Completion criteria after implementation

One ordinary clean profile reaches a real result and its exact Journal review; sees what changed; chooses next or leaves; returns and resumes valid original state. A second interest is reachable without reset. Opt-out player reaches free exploration directly. Repeat this at affected desktop/touch boundaries and actual supported hardware, with controlled fixtures kept separate from gameplay. Unchanged accepted full careers/laps are not repeated for a new card layout.
