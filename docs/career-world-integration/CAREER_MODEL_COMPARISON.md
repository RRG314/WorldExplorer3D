# Four complete progression alternatives

All alternatives retain one current character, Backpack, wallet boundary, Journal, world lifecycle and account. Basic exploration is never career-locked. Starting direction, tracked focus, active task, background, permanent practice and travel mode remain distinct concepts.

| Decision | A — Starting career + open world | B — Classless specializations | C — Career-guided sandbox | D — Profession / qualifications |
| --- | --- | --- | --- | --- |
| First screen | Choose interest or explicit Free Explorer; show useful work and suggested tools | Choose place and explore; interests emerge from practiced actions | Guided entry or roam; optionally pick one focus before/after first result | Choose a pathway; inspect evidence and capability prerequisites |
| Character creation | Suggest existing background; allow default/custom; never bind class | Existing neutral/default character, optional customization | Same original creation; interest is separate optional metadata | Same character; qualifications record evidence, not a new identity |
| Starting equipment | Original starter/course tools, one idempotent grant policy | Existing free tools and contextual recommendations | Owned items first, course-provided tools next, existing store only if needed | Required tool + qualification explanations before advanced activity |
| First objective | Real task matching chosen interest at a valid place | One obvious nearby action, then visible result | One recommended valid task; explicit unrelated choices retained | Basic training → actual evidence → advanced offering when original rules permit |
| Ongoing progression | Related tasks preferred, all valid practice counts | Skills/Journal are main navigation; no tracked profession needed | One focus influences ranking; current task always takes priority | Evidence-backed milestones and advanced capabilities structure work |
| Switching | Change direction without replacing background or resetting work | No career switch operation; choose another activity | Change optional focus; starting another task remains separate confirmation/action | Follow several pathways; earned qualifications persist |
| Multiplayer | Different chosen starts in same room | Open shared play with individual practices | Shared purpose plus one personal focus per participant | Qualified roles may assist different tasks, but room permissions stay separate |
| Data addition | Optional starting-interest reference and intro progress | Little new state; stronger derived views | Optional starting interest / active focus metadata, existing tutorial/task state | Qualification definitions/award evidence and curriculum; highest content obligation |
| Strength | Clear fantasy and initial preparation | Lowest lock-in, minimal duplication | Clear next step plus freedom; strongest fit for mixed experience | Deep specialist identity and meaningful advanced preparation |
| Principal risk | Choice before understanding; false implication of permanent class | Directionless new player; skills can become a wall of numbers | Becomes another panel unless one projection replaces overlapping hints | Empty credential ladder, grind, content inflation and access locks |
| Migration | Existing players may decline; never replay creation/grants | Mostly new view, no reset | Optional metadata defaults to no focus; retain current tasks | Must map old evidence conservatively; no retroactive lockouts |

## Scorecard (design judgment, 1 weak–5 strong)

| Criterion / weight | A | B | C | D |
| --- | ---: | ---: | ---: | ---: |
| Mixed-age beginner clarity / 30% | 4 | 2 | 5 | 3 |
| Freedom and switching / 25% | 4 | 5 | 5 | 3 |
| Fit with actual source owners / 25% | 4 | 5 | 5 | 3 |
| Delivery/migration restraint / 20% | 4 | 5 | 4 | 2 |
| Weighted score | 4.00 | 4.10 | 4.80 | 2.80 |

These are explicit reviewer judgments, not user-study statistics. Recommendation: **C**, using existing classless practice and selected qualifications as optional depth. This is a recommendation awaiting owner approval, not an already selected architecture. Model B remains an excellent expert/free-exploration mode. Model A is an optional early-choice flow. Model D can later describe real advanced work without becoming a mandatory universal framework.

## Concrete outcome under each model

A Geologist examines an authored exposure, keeps the actual record, later flies to a supported destination and documents planetary geology. In A, their initial career biases suggestions. In B, Geology and Space practice become visible through use. In C, the tracked focus ranks a suitable next task but the active mission governs guidance. In D, evidence can satisfy a defined qualification when the original curriculum actually awards it. In every case there is one canonical sample/event and the same world/mission/custody authority.

See the [interactive preview](index.html): changing model changes entry CTA and pathway emphasis; onboarding and composition are independently selectable. The native contracts verify existing authority feasibility, not a new focus backend or finished profession system.
