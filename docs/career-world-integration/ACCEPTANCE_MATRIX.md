## Post-approval actual acceptance (phases18–21)

1. New player: ordinary clean profile → approved first flow → actual task → committed result → exact Journal → understandable next step, with skip/replay/interruption.
2. Returning Explorer: no forced creation/reset/grants; switch focus and concrete task safely; prior character/items/homes/vehicles/studies/media preserved.
3. Geology/mining: genuine cited references distinct from authored station/occurrence/material; original field method/custody/processing boundaries; outages and supported geography honest.
4. Multiplayer: two connected clients with different focuses in same original room; valid membership/frame/individual evidence and no duplicated rewards. Any newly approved cooperative task adds server contribution/settlement acceptance.
5. Full app: affected Earth/Ocean/Space/planetary/interior/travel/mobile/VR/platform paths, persistence, permissions, performance and exact staging artifact. Reuse unchanged accepted evidence; re-open demonstrated dependency failures only.
6. Required release CI/security/dependency/type/ownership, immutable identity/hosted parity, licenses, backup/rollback and exact owner review. Do not deploy production automatically.

Source checks, controlled fixtures, real input, live providers, exact hosted candidate and physical hardware remain distinct. An incomplete or interrupted run is never a pass. All failed evidence stays retained.
