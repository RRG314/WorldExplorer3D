# Proposed first-time journey

Default audience: mixed ages and experience, simple entry with optional depth (owner selection). Recommendation: universal foundation first, with optional early interest and immediate free exploration. This is proposed flow B, not an implemented mandatory wizard.

| Moment | Primary player action | App response and authoritative completion |
| --- | --- | --- |
| Arrive | Explore / Get a little guidance / optional sign-in | Keep globe/search and last supported destination. Explain device save scope briefly; do not gate basic play behind account or career selection. |
| Pick a place | Selected place or clear included guided start | Original location/session owner loads; real progress/error/cancel/return. No hidden teleport to make tutorial work. |
| Move and look | Keyboard, touch, controller or VR-specific input | Original active controller observes a short valid movement. Instructions are compact, dismissible and replayable. |
| Try an action | One nearby valid interaction or offered field task | Existing router/adapters validate current world, mode, tools and geography. If no task fits, offer a known playable destination or free roam. |
| Do something meaningful | Finish the actual action/task | Commit original result. No Next-only completion or reward for opening menus. Noncollecting activity is valid. |
| Keep the result | Open exact Journal event/report | Show what happened, source/evidence, where kept and actual progression. Tutorial listens to that committed result and visible record. |
| Choose what follows | Continue interest / try another / roam | Optional focus selection, no background reset. First session ends at a durable result + understandable next choice. |

Deep character creation stays optional and uses existing background/custom rules; no new account, appearance or class schema. A returning Explorer bypasses first-time creation/grants and sees Continue from real saved state. A new account in a browser with an old local Journal is not a blank profile; offer explicit explanation and safe choices without deleting local records.

Skip means stop guidance, not lose mission progress. Resume picks current lesson step and revalidates context. Replay resets only the lesson. Leaving during load or changing destination cancels stale hints through session identity. An existing Moon transfer, vessel voyage or shared room is preserved when choosing an interest; current mission/recovery takes priority.

Control hints use actual saved bindings and current device. No prompt says “press E” to a touch-only player. Visual, audio and text presentation must support notice duration, contrast, larger text and reduced motion; hardware/assistive acceptance remains explicit. First Journal/cloud status is not buried in internal planning language.

Target for future moderated pilot: first movement within one clear instruction after readiness; one real first result and its Journal review without facilitator directions. Measure attempts/time/errors and player comprehension, with no universal success-time promise before study.
