# A — Career first

Flow: choose interest or Free Explorer → optionally review existing background → see tools and valid place → enter original activity → learn controls through first real task → keep result in Journal → continue/change/roam.

The first screen shows a few family choices with genuine imagery and one real task, with all twenty interests reachable. It explains that the choice guides work and recommendations and does not lock other play. Character background is a separate optional detail; no new class schema. Existing players bypass creation and never receive duplicate starter grants.

Best for someone arriving with a clear identity (“I want to race” or “I want geology”). Weakness: the player has not yet experienced controls, save scope or content depth; choosing can imply a permanent class. Mitigate with concrete task preview, free included tools, clear local availability and Decide later.

One focus selection alone does not start a mission. Before Start, show actual adapter place/equipment admission and any existing active trip restriction. Failure to qualify a local site offers supported travel/another task without losing choice. Tutorial completion references the actual domain result, not selection or menu visits.

Preview: choose first session A in [interactive review](index.html?intro=A&model=A&composition=field&device=desktop). Test interest→prepare→preview task/result→Journal→switch, and Free Explorer. Simulation does not award actual game progress.

Approval outcome: implement as optional early-choice route if desired; not recommended as the mandatory default for the mixed-experience audience. Release stop: original entry/result/recovery works, existing players preserved, explicit opt-out and no false grants/class locks.
