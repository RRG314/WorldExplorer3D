# B — Universal introduction, then direction

Flow: choose place or included guided start → move/look → one valid action/task → commit result → exact Journal review → choose optional interest, another activity or free exploration.

Recommended default for mixed ages/experience. It teaches the reusable interaction/result/save loop once, before twenty interest choices. Existing First Journey and First Bearings already implement much of this foundation; the source repair restores explicit requested instructions. The redesign should simplify handoff/visibility, not build another tutorial authority.

A universal introduction cannot assume every arbitrary location has the same task. At incompatible geography or during an existing voyage, preserve current context and offer an admitted local action or a clearly named supported guided destination. Do not inject a specimen, teleport or override a trip to satisfy onboarding. Keep the full globe and immediate Free Explore.

Only teach the next control. The resulting record can be observational rather than collectible. Show source, actual save scope and what changed. Next screen offers Continue this interest / Try another / Roam; no mandatory course purchase or attribute allocation. Existing players go straight to Continue, with optional help/replay.

Preview: [B introduction](index.html?intro=B&model=C&composition=field&device=desktop), plus phone selector. Native controlled prototypes verify existing character/receipt/Backpack feasibility; fresh desktop audit proves current real First Bearings outcome separately.

Risks: an overlong generic tutorial or a silent context mismatch. Bound the first loop and retain skip/resume. Release stop: meaningful committed result, exact Journal review, no reward for Next, opt-out/replay and interruption persistence, device-specific usable guidance.
