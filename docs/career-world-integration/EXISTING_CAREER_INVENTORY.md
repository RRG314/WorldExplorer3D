# Existing careers and their actual owners

The display catalog has twenty entries. Thirteen pure research domain reducers feed one `profile-store.updateResearchCareer` transaction. Other entries project pre-existing housing, mission, story, racing and companion owners. This is already a mostly classless foundation; none of these entries creates an account or a second Backpack.

Entry for every row: **Activities → career → assignment/place → original adapter**. `experiences/entry.js` validates a versioned intent, fences superseded travel and rechecks current world identity. `ui/research-careers.js` lazily mounts one selected research plugin; marine work delegates to the existing marine research lifecycle. All scientific courses below are bounded game training, not professional credentials or claims about exact real-world specimens.

These seed bounded attributes/practice and recommendations; they are not exclusive career classes. Nine specialties: Wildlife, Companion Handling, Geology, Marine Exploration, Space Exploration, Piloting, Engineering, Photography, Surveying. A proposed optional focus is none of these and must have an explicit lifecycle/migration contract before addition. Do not create twenty independent XP ladders to mirror twenty labels.
