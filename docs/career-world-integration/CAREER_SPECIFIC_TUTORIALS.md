# Career introductions tied to real work

Proposed short entry lessons over existing activities, not twenty new tutorials or menu-completion badges. Teach only the next required operation. The original domain decides success, current place, equipment, custody and save. Existing accepted course methods/results are reused; new lesson wiring is tested at entry/result/resume boundaries after approval.

## Tutorial contract

Each lesson references the existing entry ID/definition version and a known domain phase or committed event. Starting it does not supply fabricated evidence. Resume reads original state. A completed task may be reviewed rather than replayed. Missing equipment and incompatible geography have a real preparation/travel/alternative action; no indefinite empty marker. Shared room and active voyage restrictions are explained before travel.

Success is not “the user saw every tip.” For each new wiring: ordinary entry, actual next controllable operation, appropriate prompt, real saved result or preserved partial state, Journal/result linkage, next choice and opt-out. Full unchanged physical course variants stay accepted. Any newly invented activity or qualification requires its own content/acceptance gate before appearing playable.
