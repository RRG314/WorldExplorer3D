# Track creator design

Evidence date: October 28, 2026. Baseline `7da846f`; current working-source improvements are distinguished from unimplemented racing. No production deployment or purchase.

Reuse the world map's inspected selection and explicit navigation intent separation. Creator mode selects canonical roads; destination inspection must not silently move a player or overwrite a route. Main steps: select qualified city;choose sprint/circuit;place start;select contiguous segments;set laps/class/assists;preview clearances;test;save draft;publish version;share through the existing room/community entry.

Red feedback identifies the actual disconnected span,wrong-way segment,unsupported grade or too-small turning radius. Editing remains available after a failed test. Show course length,coverage boundary,traffic policy and eligible vehicle families. Store drafts separately from verified published records; reject scripts/HTML in names/descriptions and apply existing social moderation/blocking.

Temporary cones/barriers can later use scoped Blocks presentation with course ownership and lease disposal. They must not become permanent property construction or alter map provenance. Ramps cannot bypass clearance,finish validation or owned-property permissions. No track editor is declared working from this design document; see vertical-slice status.
