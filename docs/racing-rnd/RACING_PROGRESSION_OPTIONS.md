# Three progression alternatives — owner choice recorded

Evidence date: October 28, 2026. Baseline `7da846f`; current working-source improvements are distinguished from unimplemented racing. No production deployment or purchase.

Working review UI: `design-preview/racing/index.html`. It uses the selected Roam/ConceptB identity. All career figures and example results are explicitly illustrative, not current player progress.

| Model | Motivation and loop | Acquisition/upgrades | Replay/social | Cost/risk |
|---|---|---|---|---|
| Regional clubs and championships — recommended | Discover a mapped local club; qualify in an everyday car; compete in optional regional series; revisit stronger rivals | Existing Credits and garage; participation awards with idempotent server receipts; no race rank needed for ordinary vehicle use | Regional records,guest series,friend events,open exhibitions for classics/utility vehicles | Moderate; course validation and server race authority still substantial |
| Collector and skill licences | Learn disciplines through driving tests,build a collection,master favourite vehicles | Credits plus optional demonstrated-skill unlocks; usable early upgrades,not repeated grind per car | Time trials,build-specific personal bests,collection exhibitions | Moderate; tests need fair cross-input assists and meaningful practice |
| Open rivals and crew network | Discover player/AI rivals,create crews,choose a reputation path; occasional challenge invitations | Credits and vehicle build legality; reputation unlocks events rather than basic mobility | Crew events,social rivalry,player-created leagues | High; moderation,matchmaking,disconnect/reputation abuse and economic balance |

All three preserve non-racing exploration,property,Ocean/Space and ordinary transport. None requires chapters,forced police pursuit,daily streaks or car confiscation. Clubs fit geographic revisits best; licences offer a clear learning path; rivals emphasize long-term social competition. Combine elements if selected explicitly.

**Owner decision, October28,2026: Open rivals and racing crews is selected as the primary direction.** Preserve everyday ownership and optional collection/learning; regional clubs are not the primary career. The other proposals remain alternatives for reference.

The owner selected the career explicitly; its implementation follows the shared vehicle and integrated-slice acceptance requirements.
