# World Explorer 3D — embodied-agent research

This branch studies a language-model resident acting through the mapped 3D world of World Explorer. It includes the environment, bounded model interface, resource mechanics and reviewed developmental evidence. It is separate from the live application release.

**Observed:** movement, finite-resource gathering and one eating event with a measured needs increase. An unchanged repeat did not eat. Four focused tool probes produced no tool. The latest recorded all sixteen brief stated-intent summaries; its actions still did not reach crafting. Sustained survival, useful manufacturing, construction and society remain unproven.

Start with the [research overview](research/embodied-society/README.md) and [technical report](research/embodied-society/papers/pilot-technical-report.md). The [results](research/embodied-society/RESULTS.md) explain successful and unsuccessful attempts. The [observer guide](research/embodied-society/OBSERVER.md) shows how to minimize the panel, inspect resident quantities and download decision reports. The [reproduction guide](research/embodied-society/REPRODUCIBILITY.md) covers verification and local execution.

The current study retains thirteen heterogeneous developmental runs. It is not peer reviewed or a statistical benchmark. Model-stated intent is separate from observed effects and does not reveal internal reasoning. The [design review](research/embodied-society/RESEARCH-DESIGN-REVIEW.md) explains why the short window was inadequate for needs pressure. The owner selected a shorter accelerated study first. A six-hour accelerated resident/workshop window and an eight-hour real-time window are implemented and component tested. The [first accelerated launch](research/embodied-society/reports/accelerated-needs-1.md) was interrupted during world loading before any model call. No long or accelerated live result is claimed. The [accelerated protocol](research/embodied-society/ACCELERATED-NEEDS-STUDY.md) defines timing and interpretation; the memory comparison remains deferred. See the [data specification](research/embodied-society/DATA.md) for provenance and withheld records.

The application is retained as the environment dependency. Production configuration and deployment workflows are excluded. Publishing this research does not update stable, main or the live app. Read the [publication boundaries](research/embodied-society/PUBLICATION.md), [acknowledgements](research/embodied-society/ACKNOWLEDGEMENTS.md), [citation metadata](CITATION.cff), [license](LICENSE) and [third-party attribution](ATTRIBUTION.md).
