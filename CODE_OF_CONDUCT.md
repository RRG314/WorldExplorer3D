# Community Code of Conduct

World Explorer 3D welcomes thoughtful contributions from people of every background and experience level.

## Expected Behavior

- Be respectful, specific, and constructive.
- Discuss the work, not the worth of the person doing it.
- Make space for beginners while holding changes to the documented quality bar.
- Protect user privacy, production credentials, and embargoed security reports.
- Credit data providers, artists, and contributors accurately.

## Unacceptable Behavior

Harassment, threats, discrimination, sexualized conduct, deliberate disruption, doxxing, credential sharing, and publishing another person's private information are not acceptable in project spaces.

## Reporting

Report community-conduct concerns privately to the project maintainer. Report security issues through [GitHub private vulnerability reporting](https://github.com/RRG314/WorldExplorer3D/security/advisories/new), not a public issue.

The maintainer may edit, hide, or remove contributions and restrict participation when necessary to protect people or the project. Reports will be reviewed as promptly and impartially as practical.

This policy applies in repository issues, pull requests, discussions, rooms operated by the project, and other official project spaces.
