# Support

## Using the App

Use [GitHub Discussions](https://github.com/RRG314/WorldExplorer3D/discussions) for setup questions, ideas, and community help. Use the issue templates for reproducible bugs and scoped feature proposals.

Include the browser and operating system, selected destination, travel mode, expected result, actual result, and a screenshot when the problem is visual. Never post access tokens, account records, payment details, private room codes, or another user's personal information.

## Security and Account Safety

Report vulnerabilities privately through the process in [SECURITY.md](SECURITY.md). Public issues are not an account-recovery or billing-dispute channel.

## Project Funding

Core exploration and multiplayer are not pay-to-win. Optional monthly support is available through the project's [account page](https://worldexplorer3d.io/account/). Funding recognition does not grant gameplay power, moderation authority, or production access.
